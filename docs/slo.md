# RealWorldClaw 服务等级目标（SLO）

> 适用范围：`platform/api` 在线 API 服务（生产环境）
> 
> 统计周期：月度（自然月）

## 1) API 可用性（Availability）

- **目标值**：**99.5%**（月度）
- **定义**：API 在统计周期内可被成功访问的时间比例。
- **计算方式**：
  - 方式 A（推荐，基于探针）：`可用分钟数 / 总分钟数 * 100%`
  - 方式 B（基于请求）：`2xx + 3xx + 4xx 请求数 / 总请求数 * 100%`
- **告警阈值**：
  - 黄色告警：近 1 小时可用性 < 99.7%
  - 红色告警：近 15 分钟可用性 < 99.0%
- **降级策略**：
  1. 关闭非核心功能入口（推荐、搜索增强、活动流实时推送）
  2. 启用只读模式（暂停写请求）
  3. 提高缓存 TTL，减少数据库压力

## 2) API 延迟（Latency）

- **目标值**：**p99 < 500ms**（排除文件上传请求）
- **定义**：API 请求端到端处理时延 99 分位值，小于 500ms。
- **计算方式**：
  - 采样集合：`非文件上传请求`
  - 统计口径：`p99(duration_ms)`
- **告警阈值**：
  - 黄色告警：近 15 分钟 p99 > 450ms
  - 红色告警：近 5 分钟 p99 > 500ms
- **降级策略**：
  1. 降级高开销查询（分页上限下调、禁用复杂排序）
  2. 关闭非必要聚合接口
  3. 对热点接口启用强缓存或短路兜底响应

## 3) 错误率（Error Rate）

- **目标值**：**5xx 错误率 < 1%**
- **定义**：服务端错误（HTTP 5xx）在全部请求中的占比。
- **计算方式**：
  - `5xx 请求数 / 总请求数 * 100%`
- **告警阈值**：
  - 黄色告警：近 15 分钟 5xx > 0.5%
  - 红色告警：近 5 分钟 5xx > 1.0%
- **降级策略**：
  1. 快速切断高失败下游依赖（熔断）
  2. 降级为缓存数据/上次成功结果
  3. 临时关闭高风险写入入口，保护核心交易路径

## 4) 部署成功率（Deployment Success Rate）

- **目标值**：**> 95%**
- **定义**：部署流水线中成功完成并可服务流量的发布占比。
- **计算方式**：
  - `成功部署次数 / 总部署次数 * 100%`
  - 成功判定：部署完成 + 健康检查通过 + 无自动回滚
- **告警阈值**：
  - 黄色告警：连续 2 次部署失败
  - 红色告警：月度部署成功率 < 95%
- **降级策略**：
  1. 自动回滚到最近稳定版本
  2. 启动发布冻结，仅允许紧急修复
  3. 切换为金丝雀小流量发布并加强人工审批

## 5) 数据库迁移（Database Migration）

- **目标值**：**零停机（Zero Downtime）**
- **定义**：数据库 schema 迁移不引发 API 不可用，不中断在线请求。
- **计算方式**：
  - 迁移窗口内 API 可用性保持 >= 99.5%
  - 迁移前后关键接口成功率无显著下降（下降 < 0.5%）
- **告警阈值**：
  - 黄色告警：迁移期间 p99 延迟较基线上升 > 30%
  - 红色告警：迁移导致请求失败激增（5xx > 1%）或出现不可用
- **降级策略**：
  1. 采用 expand/contract 双阶段迁移
  2. 对 DDL 使用在线变更/分批变更策略
  3. 触发异常时立即停止迁移并执行回退预案

---

## 观测与实现说明

- 应用层提供实时 SLO 指标接口：`/api/v1/health/slo`
- 可选提供 Prometheus 文本输出：`/metrics`
- 当前实现为**内存计数器**，适合单实例或开发验证；生产多实例场景建议汇聚至统一监控系统。
